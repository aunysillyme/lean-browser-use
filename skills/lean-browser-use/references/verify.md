# Verify the result

A route's DONE is a claim. Main checks the consequential values against the artifact before repeating them to the user. Read the saved extraction file, compare the supplied URL and fields, and inspect any failed or truncated fields. For a public page, an independent `curl` fetch can provide a separate check when it contains the same data.

For logged-in work, preserve a narrow read-back from the selected tab as evidence. Main inspects that saved file. A changed page may require a fresh runner read within the existing permission scope. A successful tool call alone does not prove a form field landed or that a submission completed.

Wait for elements, not elapsed time. A bounded condition wait reports found or absent. Stop on absence and explain the missing condition. Screenshots are proof, not navigation: use observed control refs for actions, and request a scaled screenshot or region only when visual evidence matters.

Compare the artifact to the brief's observable success checks, including scope and cleanup. Return confirmed fields separately from failed or unverified ones. Preserve the evidence needed to reproduce the conclusion without exposing secrets.
