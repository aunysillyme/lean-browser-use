BROWSER USE FOR AI AGENTS

Cut browser use cost by about 25%.
A fresh runner, bulk reads, three guards.

lean-browser-use for Claude Code: a subagent does the page work in a fresh context. In two measured runs the same browser task cost 3% and 25% less than in a plain session, about 14% less together (list API prices). Whole-run tokens rose in both runs, so the saving is in dollars. The headline uses the best of two runs on one setup, with no guaranteed saving.

WHAT THE INSTALLER GIVES YOU

For Claude Code users who run browser work in their sessions. You get a skill, a runner agent (a fresh subagent that does the browser work), three hooks and a token meter (the measure command that counts tokens per step).

Common questions

FROM THE README
How do I install browser-use tools for Claude Code?

Run npx lean-browser-use, then start a fresh Claude Code session and invoke the skill. The installer copies the method, runner, briefs, and guards into your selected Claude config directory.

Can a subagent run browser work on its own?

Yes: the subagent runner handles the full browser route with the same packets. Run npx lean-browser-use doctor to inspect the tools your machine provides, then follow the route table.

How do I install into just this project?

Run npx lean-browser-use --project to target the current project's .claude directory. Check it with npx lean-browser-use doctor --claude-dir ./.claude.

How do I add the page reader and search?

Run npx lean-browser-use --with-reader to copy both companions. The reader and search companions use tools you install separately; see their setup guides: reader and search.

How do I check browser hooks after installing?

Run npx lean-browser-use doctor; hook behavior on your Claude Code version is confirmed there. For payload examples and stop rules, read the guards guide.
