# Maintainers

[Auny](https://github.com/aunysillyme) maintains lean-browser-use for Auny LLC and contributors. [CODEOWNERS](.github/CODEOWNERS) identifies the review owner.

Maintainers review observable behavior, fixtures, privacy checks, package measurements, and documentation together. Release work follows [RELEASING.md](RELEASING.md). Contributors are welcome to take on reproducible issues and improve the method through measured use.
